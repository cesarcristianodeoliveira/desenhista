# Desenhista

Ferramentas para criação visual.

## Canvas

Canvas é o primeiro produto da Desenhista.

Seu objetivo é permitir a criação de peças visuais simples, com elementos que podem ser adicionados, manipulados e exportados como imagem.

## MVP 0.0.1

A primeira versão do Canvas terá como objetivo:

- criar um documento visual;
- adicionar elementos;
- selecionar e manipular elementos;
- exportar o resultado em PNG.

## Tecnologia inicial

- React JS
- Fabric

## Não incluído nesta versão

- usuários e autenticação;
- backend;
- inteligência artificial;
- pagamentos;
- marketplace;
- sistema de templates;
- colaboração em tempo real.

A prioridade é construir uma base mínima, funcional e extensível.
